DOCUMENT: CORP-01-B
TITLE: Synthetic Braking Architecture
REVISION: B
SECTION: Overview
This synthetic high-level design describes the braking software architecture.
It defines 5 software components, 3 interfaces and 7 signals.

SECTION: Component Catalogue
- SeatDriver: arbitrates access to shared vehicle resources.
- LightingController: coordinates requests from other software components.
- ChargingDriver: arbitrates access to shared vehicle resources.
- BrakeService: reports diagnostic events to the diagnostic manager.
- SeatService: monitors the health of connected sensors.

SECTION: Signals
The BrakeService publishes the WheelState signal via the WheelStatusInput port and the SeatDriver consumes WheelState.
The SeatService publishes the PedalCurrent signal via the CabinFeedChannel port and the ChargingDriver consumes PedalCurrent.
The BrakeService publishes the CruiseRequest signal via the CabinFeedChannel port and the SeatDriver consumes CruiseRequest.
The SeatDriver publishes the VehicleRequest signal via the CabinFeedChannel port and the SeatService consumes VehicleRequest.
The SeatDriver publishes the CabinLevel signal via the CabinFeedChannel port and the SeatService consumes CabinLevel.
The SeatService publishes the WiperTemperature signal via the WheelStatusInput port and the SeatDriver consumes WiperTemperature.
The ChargingDriver publishes the AmbientPosition signal via the WheelStatusInput port and the LightingController consumes AmbientPosition.

SECTION: Interfaces
The BrakeService provides the GatewaySpeedInfo interface to the SeatDriver component for PedalCurrent.
| BrakeService | GatewaySpeedInfo | SeatDriver | PedalCurrent |
The SeatDriver provides the MirrorTorqueService interface to the LightingController component for PedalCurrent.
| SeatDriver | MirrorTorqueService | LightingController | PedalCurrent |
The SeatDriver provides the SensorSpeedService interface to the LightingController component for WheelState.
| SeatDriver | SensorSpeedService | LightingController | WheelState |

SECTION: Dependencies
The SeatService component depends on LightingController for PedalCurrent.
The BrakeService component depends on ChargingDriver for PedalCurrent.
The ChargingDriver component depends on SeatDriver for VehicleRequest.
The SeatDriver component depends on SeatService for WiperTemperature.
The BrakeService component depends on SeatService for WheelState.

SECTION: Test Considerations
Each interface requires one positive and one negative integration test.
